Audit Report - Locus 9:124800001-126050000 (nearest gene MAPKAP1)

This file preserves everything excluded from the main evidence table (`evidence_tables/9_124800001-126050000.md`) plus the full, verbatim red-team-skeptic reasoning for genes marked CONTESTED or WEAKENED, so a reviewer can trace every judgment call. Hand this file to internal reviewers only — do not distribute alongside the public evidence table without review, per pipeline instructions.

Coordinate discrepancy flag (STRBP, PTGS1)

Both the researcher (via direct Ensembl REST API query) and red-team-skeptic (independently, via its own Ensembl REST API fetch) confirmed the following GRCh38 coordinates: - **STRBP**: chr9:123,109,494-123,269,102 — approximately **1.53 Mb outside** (upstream/ centromeric of) the stated locus start boundary (9:124,800,001). - **PTGS1**: chr9:122,370,530-122,395,877 — approximately **2.40 Mb outside** the stated locus start boundary — the largest offset of any candidate gene evaluated at this locus.

Both genes were provided as candidates via internal prioritization methods (MAGMA for STRBP, PoPS for PTGS1) that, per the pipeline's own methodology description, are expected to nominate genes that physically overlap the locus window. Neither researcher nor red-team-skeptic could resolve the cause of this discrepancy from outside the pipeline — possible explanations raised include a genome-build mismatch (GRCh37 coordinates misread as GRCh38) in the internal MAGMA/PoPS pipeline, a MAGMA gene-assignment window wider than the locus's own stated boundaries, or a locus-boundary-definition error upstream of this analysis. **This should be checked against the internal pipeline's own coordinate source before either gene is weighted further at this locus.** By contrast, PBX3 (chr9:125,656,780-125,976,687), MAPKAP1, and PBX3-DT/LOC51145 were all confirmed to fall within the stated region as expected.

Genes marked CONTESTED or WEAKENED by red-team-skeptic (full reasoning, verbatim)

MAPKAP1 — CONTESTED

**(a) Specificity:** Entirely borrowed context — general mTORC2/SIN1 biochemistry and cancer-cell (including a Kras-driven lung-tumorigenesis mouse model) biology. Zero COPD or lung-function GWAS literature.

**(b) Smoking/pulmonary/immune:** None of the three priors are supported by anything beyond proximity; no citation touches airway inflammation, spirometry, or smoking behavior.

**(c) Internal contradiction / LD bias:** This is the textbook nearest-gene-bias case the framework warns about. OT's own L2G-style scores at the same shared variants are consistently lower for MAPKAP1 than for PBX3 across 7 independent GWAS studies — the statistical evidence actively argues against MAPKAP1 relative to its neighbor, at every comparison point.

**Verdict: CONTESTED.** Nearest-gene status is not supported by fine-mapping (41/45 variants are in PBX3 introns, not MAPKAP1), L2G ranking is systematically lower than PBX3's at shared variants, and the literature is oncology/general-biochemistry with no lung-disease link. This looks like a clean instance of "nearest gene by name, not by evidence."

STRBP — CONTESTED

**(a) Specificity:** All four citations are testis/spermatogenesis biology (fish, mouse) or EMT/splicing regulation in pancreatic cancer and lens epithelium — none lung- or COPD-relevant.

**(b) Smoking/pulmonary/immune:** Unsupported; no citation touches any of the three.

**(c) Coordinate discrepancy — independently confirmed:** [Skeptic] fetched Ensembl directly (not just trusting the researcher's own lookup) and got the identical coordinates: chr9:123,109,494-123,269,102 (GRCh38), ~1.53 Mb outside the locus window's start boundary (124,800,001). STRBP is not plausibly at this locus as the locus is currently bounded. This is either a genome-build mismatch in the MAGMA pipeline (e.g., GRCh37 coordinates misread as GRCh38), an overly generous MAGMA gene-window setting, or a locus-boundary-definition error upstream of this analysis — any of which should be checked before STRBP is carried forward. Combined with zero OT COPD evidence and zero disease-relevant literature, there are now three independent reasons to doubt STRBP (wrong location, no genetic database support, no relevant biology).

**Verdict: CONTESTED.** Recommend synthesis-lead treat this as likely a MAGMA/coordinate- pipeline artifact rather than a genuine candidate at this locus, and flag for a build/window sanity check.

PTGS1 — CONTESTED

**(a) Specificity:** The OT COPD score (0.294) is driven almost entirely by clinical_precedence (approved NSAID drug target), not genetics — zero gwas_credible_sets evidence. This is a case where a superficially substantial-looking database score conflates "this gene is a drug target for a respiratory-adjacent condition" with "this gene has genetic evidence at this COPD locus." The literature itself is pharmacology of a different disease (aspirin-exacerbated respiratory disease, a subset of asthma) via drug-induced COX-1 inhibition — not genetic variation in PTGS1 causing COPD.

**(b) Smoking/pulmonary/immune:** Not supported; the AERD mechanism (loss of protective PGE2 → mast-cell/leukotriene bronchoconstriction upon NSAID exposure) is a pharmacodynamic adverse-event pathway, categorically distinct from smoking-mediated or structural COPD biology.

**(c) Contradicting evidence:** Pidgeon et al. 2004 is a direct negative finding — COX-1 knockout had no effect on hypoxia-induced pulmonary hypertension in rats, while COX-2 knockout worsened it. This argues against a structural/vascular pulmonary role for COX-1 loss-of-function, which is the more relevant genetic model (COPD GWAS signals typically act via expression/dosage, closer to a knockout/knockdown model than to acute pharmacological inhibition).

**(d) Coordinate discrepancy — independently confirmed:** Ensembl REST lookup gives chr9:122,370,530-122,395,877 (GRCh38), ~2.40 Mb outside the locus window — the largest offset of any candidate gene at this locus. PTGS1 is not plausibly within the credible-set LD block as currently defined.

**Verdict: CONTESTED.** No genetic (L2G/credible-set) evidence at all, a coordinate offset larger than any other candidate, a literature base describing a different-disease pharmacological mechanism rather than genetic etiology, and one direct negative finding in a pulmonary vascular-remodeling model. This is close to the clearest case of overclaiming among the five genes: a nontrivial-looking OT score that on inspection is genetics-free.

PBX3-DT / LOC51145 — CONTESTED

**(a) Specificity:** No literature exists under either symbol — an evidence vacuum, not a refutation.

**(b) Smoking/pulmonary/immune:** Cannot be assessed; no data.

**(c) Internal contradiction / LD bias:** PBX3-DT is divergently transcribed from PBX3, meaning the two genes very plausibly share a bidirectional promoter/regulatory element. An ABC (activity-by-contact) enhancer-gene link to PBX3-DT could simply be indexing the same regulatory activity that also targets PBX3, rather than providing independent evidence that the lncRNA itself is the functional unit. This is a case worth flagging explicitly under the "LD/nearest-gene bias" heading, generalized to "shared-promoter bias": the ABC signal may not distinguish PBX3-DT from PBX3 at all.

**Verdict: CONTESTED** — not because of contradicting evidence, but because of total absence of evidence beyond a single computational prioritization method whose signal is plausibly non-independent of the far-better-evidenced neighboring gene PBX3. Recommend synthesis-lead treat ABC-prioritization of PBX3-DT as likely reflecting shared regulatory architecture with PBX3, not as independent support for the lncRNA as a distinct causal gene.

PBX3 — WEAKENED (not CONTESTED, but flagged with substantial caveats)

**(a) Specificity:** Mixed. The strongest quantitative case (highest OT COPD score 0.431, highest genetic_association score 0.709, L2G-style scores 0.47-0.78 consistently beating MAPKAP1 at every shared variant across 7 studies, 41/45 credible-set variants in its introns) is a database/statistical case, not a literature case. The literature is almost entirely borrowed from unrelated contexts: hematopoiesis/leukemia biochemistry (Milech, Abramovich), NSCLC oncology (Zhao et al. — cancer cell lines, not COPD), and Pbx1/2/3 combined-knockout developmental biology in spleen/general organogenesis (Zewdu, Selleri) — not lung. A targeted search for PBX3 + FEV1/lung-function GWAS, + asthma GWAS, + smoking-initiation GWAS, + lung branching morphogenesis, + lung immune-cell function returned zero hits, per the researcher. That is a striking literature vacuum for the top-ranked gene at the locus.

**(b) Smoking vs. pulmonary-function vs. immune:** The OT colocalization pattern is informative and should be weighed carefully: strong coloc (h4>0.8) with "Smoking status – Current," asthma, and FinnGen "chronic lower respiratory diseases," but inconsistent coloc with FEV1 (0.36-0.81) and with COPD itself (0.02-0.95 depending on study pair). That pattern — strong on smoking/asthma/broad-chronic-respiratory-disease, weak/inconsistent on FEV1 and COPD-specific — is more consistent with prior #1 (smoking-mediated or broad airway-inflammatory-disease pathway) than with prior #2 (direct pulmonary-function/ structural biology). But this is a database-coloc-only claim: the one primary-literature citation offered to substantiate the smoking link (GSCAN, Liu et al. 2019) was flagged CLAIM_MISMATCH — the abstract never mentions PBX3 or 9q33. So the smoking-mediation story is asserted by OT's pipeline, not corroborated by any primary literature the researcher could find. Treat it as a plausible but literature-unconfirmed hypothesis, not established biology.

**(c) Internal contradictions:** Two significant ones. (1) The one piece of evidence that most directly ties PBX3 to lung tissue — Williams et al.'s PBX3-intronic variant, genome-wide-significant for hospitalised respiratory infection and colocalizing with a lung eQTL (risk allele → decreased PBX3 expression) — failed to replicate in the Stage-2 meta-analysis of 11 cohorts. This was the single most mechanistically direct (tissue- specific, directionally-resolved) result in the entire PBX3 literature base, and it didn't hold up. (2) The COPD-itself colocalization ranges from h4=0.02 to h4=0.95 across different GWAS Catalog COPD study pairs — internally inconsistent evidence for the trait the pipeline actually cares about, on top of a locus that is described as a broad pleiotropic LD block (co-localizing with HDL subfractions, height, dental/pain phenotypes), raising real concern about whether "the PBX3 signal" is one causal mechanism or several distinct signals bundled by LD.

**(d) TALE-homeodomain identity — smoking/neurobehavioral vs. lung-developmental vs. ambiguous:** Genuinely ambiguous, but if forced to weight the available evidence, it leans slightly toward smoking/broader-airway-inflammatory-disease over classic structural/developmental COPD biology — driven by the OT coloc pattern (strong with smoking-status and asthma/chronic-lower-resp-disease, weak/inconsistent with FEV1 and COPD-itself) and by the complete absence of any literature on PBX3 in lung development or airway epithelial biology specifically (its developmental role is demonstrated in hematopoiesis/spleen/general organogenesis, not lung — extending that to "lung development" is analogy, not evidence). This lean is weak and should be reported as a hypothesis, not a conclusion.

**Verdict: WEAKENED.** The fine-mapping and relative L2G ranking genuinely distinguish PBX3 from its neighbors (this is not a nearest-gene-bias problem — quite the opposite, PBX3 correctly outranks the nearest gene MAPKAP1). But the inference that PBX3 has a demonstrated, COPD-specific, lung-relevant mechanism overreaches what the evidence shows: the single lung-tissue-specific finding failed replication, the smoking-mediation claim lacks primary-literature confirmation, the COPD/FEV1 colocalization is internally inconsistent across studies, and the locus is pleiotropic enough that mechanism (smoking vs. structural vs. immune vs. something else entirely) remains genuinely unresolved. Report PBX3 as the strongest gene-identity candidate at this locus with an unresolved, contested mechanism — not as a validated COPD-lung gene.

Disclosed search-coverage limitations (both subagents)

- **Researcher**: WebSearch budget was exhausted partway through the research task (session-level limit); all further research relied on PubMed and bioRxiv/medRxiv MCP tools (already the pipeline's stated primary source). WebFetch (used for Ensembl REST API lookups) remained available. - **Red-team-skeptic**: All WebSearch calls failed on an exhausted session-wide budget before returning any results — no independent literature search or contradiction-hunting was performed for any gene in this critique. The two WebFetch coordinate checks (STRBP, PTGS1 via Ensembl REST) succeeded and independently corroborate the researcher's own coordinate flags exactly. Everything else in the skeptic's critique above is critique-by-reasoning over the supplied verified findings, not new evidence-gathering. This gap is most consequential for PBX3-DT and MAPKAP1, where an independent contradiction-search was never completed by anyone in this pipeline run.

Additional genes in region (not carried into main evidence table)

Per pipeline scope (only genes flagged by an internal prioritization method or physically dominant in the credible set are full candidates), the researcher additionally enumerated — via direct Ensembl REST API region query — ten other protein-coding genes physically within the stated locus window that were not flagged by any prioritization method: GOLGA1, PPP6C, RPL35, WDR38, HSPA5, SCAI, OLFML2A, ARPC5L, RABEPK, GAPVD1. This is noted here for completeness; none of these ten genes were escalated to full gene-block treatment or included in the main evidence table, per the researcher's own judgment call, which synthesis-lead did not override.
